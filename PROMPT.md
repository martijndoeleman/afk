# Tasks
This file is the prompt. It is sent to you verbatim at the start of every
iteration, in a fresh session with no memory of the previous one. Everything you
need to know is here or in the repository.

## How to work

- Pick the first item not marked [x] and complete it.
- Mark it [x] and commit your work with a descriptive message.
- Do exactly ONE item, then stop.
- If every item is already [x], reply with exactly: ALL_DONE
